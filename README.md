# Scope
Collection of my Home Assistant files that are discussed in online videos.

This site is organized by Video Number.

# myHA Video Guide by Subject

Updated: **12 August 2026**

This guide organizes the videos by **Subject** in **alphabetical order**.


## Audio / I2S

- **Video 77 — ESPHome Audio and LVGL**
  - Uses ESPHome I2S components to play sounds with LVGL widgets.
  - Covers ESPHome audio components and the Waveshare ESP32-S3 Touch-LCD-3.5C, including its audio codec, microphone, and speaker.
  - [Video 77 files and README](./Videos/video77/)

## Cameras / ESP32 Web Cams

- **Video 57 — Low-Cost ESP32 Web Cams**
  - Compares three ESP32-based web cameras.
  - Covers ESPHome configuration, Home Assistant screens, camera capabilities, and test results.
  - [Video 57 files and README](./Videos/video57/)

## 3D Printing / Device Mounting

- **Video 84 — Device Demonstration, LVGL Meter, and 3D Mount**
  - Explores an ESPHome/LVGL device and enhances its manufacturer's demo with an LVGL Meter widget.
  - Includes a 3D-printed mounting solution.
  - [Video 84 files and README](./Videos/video84/)

## ePaper Displays

- **Video 61 — ESPHome ePaper Display**
  - Configures an ePaper display using positional layouts and dashboard snapshots.
  - Uses an ESP32-S3 USB board and discusses the Waveshare ePaper display and the Home Assistant Puppet add-on.
  - [Video 61 files and README](./Videos/video61/)

## ESP32-C6 / Zigbee

- **Video 94 — ESP32-C6 Zigbee**
  - Explores the ESP32-C6 Zigbee capabilities.
  - Covers Zigbee End Device vs. Coordinator concepts, the Zigbee Map, adding Zigbee devices, and the ESPHome Device Builder.
  - [Video 94 files and README](./Videos/video94/)

## ESP32-P4 / Relays

- **Video 70 — ESP32-P4 Integrated Relays**
  - Configures and controls the two relays on the Waveshare ESP32-P4 Display Panel.
  - Uses LVGL graphic objects to interact with the relays.
  - [Video 70 files and README](./Videos/video70/)

## ESP32-P4 / RS485 / Modbus

- **Video 72 — RS485 Interface with ESPHome and LVGL**
  - Configures the RS485 interface on the Waveshare ESP32-P4 Display Panel.
  - Uses an ESPHome Modbus device and LVGL controls to extend the system with additional control devices.
  - [Video 72 files and README](./Videos/video72/)

## ESPHome LVGL Basics

- **Video 46 — Getting Started with LVGL on ESPHome**
  - Introduces LVGL on ESPHome using an ILI9341 display and touchscreen.
  - Demonstrates ESPHome Cookbook LVGL examples and walks through display, touchscreen, wiring, and basic configuration.
  - [Video 46 files and README](./Videos/video46/)

- **Video 47 — LVGL on ESP32 with ESPHome**
  - Builds on Video 46 with an ESP32-S3 test rig.
  - Covers ILI9341 display/touchscreen setup, ESPHome configuration, and additional features applicable to ESP32 and Pico W.
  - [Video 47 files and README](./Videos/video47/)

## ESPHome LVGL Designer

- **Video 101 — ESPHome LVGL Designer**
  - Introduces a workflow for creating attractive graphical user interfaces for ESPHome projects using LVGL.
  - Demonstrates the ESPHome LVGL Designer online tool.
  - [Video 101 files and README](./Videos/video101/)

## LVGL 9.5 / Raspberry Pi Pico

- **Video 87 — LVGL 9.5 Screen Rotation**
  - Looks at the ESPHome 2026.4 release and the update to LVGL 9.5.
  - Demonstrates a simple LVGL 9.5 screen, screen rotation through all four orientations, buttons, and slider testing.
  - [Video 87 files and README](./Videos/video87/)

- **Video 91 — Raspberry Pi Pico-2W and LVGL 9.5**
  - Covers ESPHome support for the Raspberry Pi Pico family.
  - Walks through building and deploying ESPHome on a Pico-2W and demonstrates LVGL 9.5 widgets with advanced styles.
  - Also discusses the LVGL simulator for ESPHome.
  - [Video 91 files and README](./Videos/video91/)

## LVGL Widgets / Styling

- **Video 87 — LVGL 9.5 Widgets and Rotation**

- **Video 91 — LVGL 9.5 Advanced Styles**

  - [Video 91 files and README](./Videos/video91/)

## Round Touch Displays

- **Video 99 — Round Display Local Voice Assistant**

## Touch Displays / GC9A01

## Voice Assistant

- **Video 99 — Local Voice Assistant with ESPHome**

## Weather

- **Video 49 — Home Assistant Weather Data with LVGL**
  - Fetches default Home Assistant weather information and displays it on an LVGL display using ESPHome.

  - [Video 49 files and README](./Videos/video49/)

- **Video 50 — Home Assistant Weather Data with LVGL**
  - Continues the Home Assistant weather/LVGL work.
  - Covers ESPHome configuration for retrieving and displaying weather information on an LVGL display.
  - [Video 50 files and README](./Videos/video50/)

- **Video 80 — Weather on the Cheap Yellow Display**
  - Configures the Cheap Yellow Display (ESP32-2432S028) to retrieve weather data from Home Assistant.
