# Scope
This is Video115 on a Home Assistant ESPHome/LVGL embedded solution. In today’s video we configure ESPHome globals to hold historical data and plot it on a custom LVGL Chart routines we integrate to our device.    

We build the ESPHome device for the ST7796 capacitive touchscreen display using data from the Xiaomi Mijia BLE (LYWSD03MMC) sensors. But you can easily reuse the custom LVGL Chart routines for other projects and data. 
 
In this video, 
 - Demonstrate the TFT Screen with selectable attributes for the Chart.
 - Review the project steps and Xiaomi Meijia BLE Devices.
 - Discuss the screen design and need for globals for historical data.
 - Describe the Test Rig.
 - Review the ESPHome configuration and custom LVGL Chart routines.

The code for this video is available at the GitHub site:
