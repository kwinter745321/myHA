# Scope
This is video 105 on a Home Assistant LVGL embedded solution. This project demonstrates the creation of a high-performance, portable Bluetooth (BLE) Scanner using ESPHome and the LVGL graphics.  The Test Rig consists of an ESP32-S3 N16R8 USB Device and a ST7796 (320x480) touchscreen display.

In this video:
 - We explain the devices and the ESPHome Component
 - We explain the BLE Advertisement data 
 - We discuss the challenges and our solution
 - Demonstrate the LVGL graphics on the display programs 
 
The code for this video is available at the GitHub site:
https://github.com/kwinter745321/myHA/tree/main/Videos/video105
