# Scope
This is Video 103, on a Home Assistant ESPHome embedded solution.  We provide another example of creating an attractive graphical user interface (GUI) for an ESPHome project using LVGL and using the new online tool called the ESPHome LVGL Designer. Also, a new user to Home Assistant's LVGL, will like that we show each step for creating: (1) an ESPHome device, then (2) creating the GUI in the Designer, and finally (3) integrating the ESPHome sensors and LVGL components.

The video is intended to help makers and Home Assistant enthusiasts learn how to improve the appearance of ESPHome touchscreen interfaces using the ESPHome LVGL Designer. Rather than focusing on sensors or automation logic, the emphasis is on designing clean, professional-looking GUIs quickly and easily.

In this video, We:
 - Demonstrate the final program showing both screens. 
 - Use the Cheap Yellow Display (ESP32-2424S012C) as the demonstration hardware. Its an ESP32-C3 device. 
 - Cover the hardware layout, wiring for the display and touch controller, and sample ESPHome configuration. 
 - Show all three stages of development.

Because this is an in-depth step-by-step tutorial, there is a brief introduction before you watch each of the three stages.  And due to the length of this video, we provide times for the various sections:
Demo (1) Showcase the two screens after completing the three stages   Start time: 01:00
Demo (2) Stage 1 - Create ESPHome Device using the ESPHome Builder    Start time: 05:00
Demo (3) Stage 2 - Create the GUI using the ESPHome LVGL Designer     Start time: 20:50
Demo (4) Stage 3 - Integrate the GUI with the ESPHome Sensors         Start time: 52:20
